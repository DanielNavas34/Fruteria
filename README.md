# 🍎 Frutería Del Valle

Una aplicación web interactiva y ligera para comprar fruta fresca por internet, desarrollada con Vanilla JavaScript, HTML5 y CSS3.

## ✨ Características

- 🥑 **Catálogo dinámico:** Generación reactiva de productos a partir de datos estructurados.
- 🛒 **Carrito interactivo:** Adición y eliminación de productos con actualización inmediata de unidades y precio total.
- 📱 **Diseño responsive:** Interfaz fluida adaptable a dispositivos móviles, tablets y ordenadores mediante CSS Grid y Flexbox.
- ⚡ **Sin dependencias externas:** Código nativo, limpio y de alto rendimiento.

## 🛠️ Tecnologías

- **HTML5:** Marcado semántico y accesible.
- **CSS3:** Estilos modernos con Flexbox, CSS Grid y efectos de transición.
- **JavaScript (ES6+):** Gestión de estado en memoria y manipulación directa del DOM.
